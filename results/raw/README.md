# results/raw/

Raw per-run response logs from the harness. One file per (model, task, run) triple, typically JSON or JSONL.

Contents are gitignored by default (see repo `.gitignore`) — these files can be large and are reproducible from the benchmark and harness. A `.gitkeep` keeps the directory tracked. Snapshots corresponding to published results will be released separately (e.g. on Zenodo) and referenced by DOI from the paper.
