# results/

Evaluation outputs.

- `raw/` — per-run response logs (one file per model × task × run); largely gitignored, with a `.gitkeep` placeholder
- `analysis/` — notebooks and scripts that consume `raw/` and produce metrics, tables, and figures
- `figures/` — final figures used in the paper and README

Published results snapshots will be tagged in git so they can be cited by commit SHA.
