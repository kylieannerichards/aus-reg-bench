# Contributing

`aus-reg-bench` is a research benchmark under active development. The v0.1 scaffolding is being put in place ahead of a first substantive release targeted for mid-2026.

At this stage the project is not open for external contributions. The task design, corpus construction, and evaluation methodology are still being finalised, and accepting contributions now would make it harder to keep the benchmark internally consistent and citable.

Contributions will be welcomed after the v0.2 release, once the methodology, task formats, and evaluation harness have stabilised. At that point this document will be expanded with:

- How to propose new benchmark items
- Reviewer/expert validation process
- Coding standards for harness and corpus build scripts
- How to add a model adapter

In the meantime, if you have spotted an error, or you are an Australian regulatory expert interested in contributing items post-v0.2, please open a GitHub issue to flag it.
