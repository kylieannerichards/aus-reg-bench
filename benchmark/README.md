# benchmark/

Benchmark task items, organised by task type under `tasks/`.

Each task subdirectory contains:

- Item files (JSON or JSONL, one item per line) defining prompts, expected answers, and metadata
- A task-specific `README.md` describing format, scoring, and provenance

Benchmark items are released under CC-BY 4.0. Source regulatory text is *not* redistributed here — it is fetched locally via `corpus/` build scripts.
